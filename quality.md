# Quality

## Definition of Done — Coin Package
- Inventory ID and measurements
- Photos (obverse, reverse, edge, scale, weight)
- Verified vs probable vs unknown clearly separated
- Completed-sale comps (not just asking prices)
- Uncertainty flags (cleaning, damage, counterfeit risk, grading)
- Platform-ready title and description
- Auction format / start / reserve / timing recommendation

## Non-negotiables
- No silent authenticity or grade claims
- Upstream provenance documented when used
