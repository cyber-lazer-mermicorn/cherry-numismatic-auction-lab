# Cherry Numismatic Auction Lab

**Collectibles-commerce lane** — coin intake through photography, attribution, comps, listing, and auction strategy.

## 1. What this project does
Processes coins from intake to proposed auction listing with explicit separation of verified facts, probable attribution, and uncertainty.

## 2. Who it is for
Cherry, collectors, and portfolio reviewers evaluating evidence-heavy commerce skill.

## 3. What exists today
Foundation structure. Upstream GlacierEQ connection pending exact repo access.

## 4. What is planned
One coin processed end-to-end: intake → photos → attribution → comps → listing → auction strategy → results capture.

## 5. What it does not claim
AI never silently asserts authenticity, grade, or value. Uncertain claims stay visibly uncertain. No independent brokerage claims.

## 6. First proof artifact
One coin processed from intake through proposed auction listing, with uncertainty flags and completed-sale comps.
